# Robotic Navigation and Exploration - HW3-2

### 簡誌加 N26140692

---
## 深度強化學習應用：Unity 賽車自動駕駛

在 HW3-2 中，我們將強化學習 (RL) 應用於更複雜的 3D 模擬環境，使用 Stable-Baselines3 的 **PPO (Proximal Policy Optimization)** 演算法來訓練賽車尋找 Checkpoints，並學會避開懸崖與泥沼。

核心實作包含兩個重要部分：
1. **Reward Function (獎勵函數) 的精細設計**
2. **Domain Randomization (環境隨機化) 的訓練策略**

---

## 獎勵函數設計 (1/2)：目標引導

要讓模型學會抵達目的地，我們設計了以下兩種主要的正向獎勵：

* **Flag Capture Reward (Checkpoint 獎勵)**：
  當 `current_checkpoint > prev_checkpoint` 時給予高分 (`+100`)，明確引導最終破關目標。
  
* **Distance Reward (距離引導)**：
  計算當前與過去和目標的距離差距。靠近時給予 `+1.0`；遠離時給予 `-0.1` 懲罰。
  > 💡 **改進技巧**：刻意降低遠離的懲罰 (從 -1.0 降至 -0.1)，這能避免模型陷入「局部最佳解 (Local Optimum)」，使它為了避開水坑而敢於「稍微繞路」。

---

## 獎勵函數設計 (2/2)：生存與速度

* **Survival Reward (死亡懲罰)**：
  給予巨大的死亡懲罰 (`-1000`)，平時活著給予 `+0.1`。
  
* **Speed / Time Reward (時間與推進紅利)**：
  * **時間懲罰**：每幀固定扣除 `-0.1`，促使 Agent 尋找「最快」路徑。
  * **推進速度紅利**：利用前進的進度給予獎勵 (`progress * 5.0`)。這深刻教會了模型**主動避開減速泥沼**，因為卡在泥沼會導致推進獎勵歸零，進而被時間懲罰倒扣。

---

## 訓練策略：環境隨機化 (Domain Randomization)

為了避免模型對單一地圖**過度配適 (Overfitting)** 或是產生**災難性遺忘 (Catastrophic Forgetting)**，我們設計了自動切換地圖的訓練腳本。

* **高頻率地形切換**：
  將單一地圖訓練回合縮短至 50 個 Episodes 就強制換圖。
* **地圖難度交替 (課程學習概念)**：
  以 `Map 3 (開闊起始) -> Map 1 (極端狹窄連續彎) -> Map 2 (大緩彎)` 的隱式難度曲線進行輪替。逼迫神經網路不依賴背地圖，而是真正學會看 Lidar 與避開懸崖的泛用駕駛策略。

```bash
for i in (seq 1 34)
    for map_id in 3 1 2
        echo "=== Currently Training on Map $map_id (Loop $i/34) ==="
        python -m mlgame3d -i rl_play.py -i hidden -i hidden -i hidden -e 50 -gp items 0 -gp audio false -gp map $map_id -gp checkpoint 10 -gp max_time 120 -ng -ts 20 ./Proly.app
    end
end
```

## HW3-2 訓練成果總結

透過上述的 Reward 塑形與泛化訓練策略，最終 Agent 達成了以下表現：
1. **極高的生存率**：將死亡懲罰調高與解決連續幀扣分後，Agent 學會了精細操作方向盤，絕不踏入水池與懸崖。
2. **最佳化效率**：突破了局部最佳解，學會繞開泥沼等干擾地形，完美實現以最短時間破關的目標。
3. **高度的泛用性**：在三張截然不同的地形中都能快速找到所有 Checkpoints，成為真正具備 Generalized Navigation 能力的模型。
