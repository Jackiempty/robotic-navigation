## TODO 4: PPO 策略梯度損失 (Policy Gradient Loss)

PPO 的核心精神是透過 Clip Mechanism，將新舊策略比值 $ratio$ 限制在 $[1 - \epsilon, 1 + \epsilon]$ 的範圍內，避免單次更新幅度過大導致模型崩潰。

```python
# 計算新舊策略的機率比值 ratio = exp(log_prob_new - log_prob_old)
ratio = torch.exp(sample_a_logps - sample_old_a_logps)

# Surrogate objectives
surr1 = ratio * sample_advs
surr2 = torch.clamp(ratio, 1.0 - self.clip_val, 1.0 + self.clip_val) * sample_advs

# 取兩者之中較悲觀(較小)的值，並加上負號轉為最小化(Minimize)問題
pg_loss = -torch.min(surr1, surr2).mean()
```

透過這種方式，演算法既能保有 Actor-Critic 的良好採樣效率，又確保了訓練過程的穩定性！
